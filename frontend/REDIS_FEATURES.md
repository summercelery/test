# 前端Redis会话管理功能

前端已集成Redis会话管理功能，提供完整的用户会话体验。

## 🎯 新增功能

### 📊 **会话统计显示**
- **登录时间**：显示用户登录的具体时间
- **最后访问**：显示最后一次访问的时间
- **剩余时间**：显示会话剩余的有效时间
- **IP地址**：显示登录设备的IP地址
- **设备信息**：显示浏览器和设备信息

### ⏰ **会话时间管理**
- **延长会话**：用户可以主动延长会话时间
- **过期提醒**：会话即将过期时自动提醒
- **实时监控**：每5分钟检查一次会话状态

### 🛡️ **设备管理**
- **强制下线**：可以强制下线其他设备上的会话
- **会话隔离**：确保同一用户只能在一个设备上保持活跃会话
- **安全确认**：操作前会显示确认对话框

### 🔄 **自动会话检查**
- **定期验证**：自动检查会话有效性
- **状态更新**：实时更新会话状态
- **过期处理**：会话过期时自动跳转到登录页面

## 🎯 用户体验

### 登录流程
1. 用户输入手机号和密码
2. 点击登录按钮
3. 后端验证并创建Redis会话
4. 前端接收Token并存储
5. 跳转到仪表板

### 会话管理流程
1. 用户点击"查看会话"
2. 显示详细的会话统计信息
3. 可以延长会话时间
4. 可以强制下线其他设备
5. 实时显示剩余时间

### 登出流程
1. 用户点击"退出登录"
2. 前端调用后端登出接口
3. 后端清除Redis中的会话数据
4. 前端清除本地存储
5. 跳转到登录页面

## 🛠️ 故障排除

### 常见问题

1. **会话统计不显示**
   - 检查网络连接
   - 确认Token是否有效
   - 查看浏览器控制台错误

2. **延长会话失败**
   - 确认会话是否已过期
   - 检查后端服务状态
   - 验证API接口是否正常

3. **强制下线失败**
   - 确认是否有其他活跃会话
   - 检查Redis连接状态
   - 查看后端日志
